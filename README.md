# Customer Behavior Analysis

## 📌 Project Overview

This project analyzes customer shopping behavior to identify patterns in customer demographics, purchasing habits, product preferences, and spending behavior.

## 📂 Dataset

The dataset contains information related to customer shopping behavior, including:

* Customer ID
* Age
* Gender
* Item Purchased
* Category
* Purchase Amount
* Location
* Size
* Season
* Review Rating
* Subscription Status
* Payment Method
* Shipping Type
* Discount Applied
* Previous Purchases
* Purchase Frequency

## 🛠️ Tools Used

* Python
* Pandas
* Jupyter Notebook
* MySQL
* SQL

## 🔍 Analysis Performed

* Data cleaning and preprocessing
* Exploratory Data Analysis (EDA)
* Customer demographic analysis
* Product and category analysis
* Purchase behavior analysis
* Spending pattern analysis
* SQL queries for business insights

## 📊 Key Objectives

* Understand customer purchasing behavior
* Identify popular product categories
* Analyze spending patterns
* Compare customer behavior based on demographics
* Generate useful business insights using data

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Jupyter Notebook.
3. Install the required Python libraries:

```bash
pip install pandas
```

4. Run the notebook cells step by step.
5. Import the cleaned dataset into MySQL for SQL analysis.
